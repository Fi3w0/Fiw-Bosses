# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in FIW Bosses, please report it
privately. Do not open a public issue.

To report, create a new issue on the
[issue tracker](https://github.com/Fi3w0/Fiw-Bosses/issues) and check
"This issue is a security vulnerability" if the option is available.
Otherwise, contact the maintainer directly.

We will acknowledge your report within 1 week and aim to provide a fix
within 30 days, depending on severity.
